# AI-assisted product building

This profile documents hands-on digital product development — from initial concept and requirements to tested, playable releases.

## Current project

### Gem Bastion

An offline Android tower-defence game set in a mystical witch forest.

The project combines:

- Product concept and game design
- Gameplay systems and balancing
- HTML, CSS and JavaScript
- Android packaging and offline deployment
- Automated tests and GitHub Actions
- UI/UX iteration based on real-device testing
- AI-assisted development with OpenAI Codex

Gem Bastion is currently in private beta and has reached version 2.27.

## Development approach

AI coding agents support implementation, debugging, refactoring, testing and release automation.

Product direction, requirements, design decisions, device testing and final acceptance remain human-led.
